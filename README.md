# Worn

A calm, offline Android app for tracking daily Invisalign / clear-aligner wear time.

## Build

Requires JDK 17+ and Android SDK 35.

```bash
./gradlew assembleDebug testDebugUnitTest
```

Debug APK:

`app/build/outputs/apk/debug/app-debug.apk`

## Privacy

All data stays on device. No account, analytics, or ads.
